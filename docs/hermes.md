## Path B: final-reply hook

See [`../examples/hermes/earshot-say.sh`](../examples/hermes/earshot-say.sh) (Linux: Bash, `jq`, `nohup`, `setsid`, installed relay CLI). The real hook payload has `.extra.assistant_response` and `.extra.platform`. The command loads `earshot.env` from the **active `$HERMES_HOME`**, not `$HOME`, because a multiplexed gateway scopes each profile; this run inherited the token but **not** the API URL, so inheritance alone was insufficient. Keep that file 0600 with direct `EARSHOT_API_URL` and `EARSHOT_API_TOKEN`; this hook rejects missing/whitespace values and ambiguous `*_FILE`/relay fallback settings rather than inheriting them. Install the relay CLI and `jq` on the hook's PATH; **verify that the launcher actually executes `earshot-relay say`** rather than treating a zero exit from an inert wrapper as delivery. Register the executable as `hooks.post_llm_call[].command`, using an absolute path; give the hook explicit consent (`hooks_auto_accept` or `hermes gateway run --accept-hooks`). It detaches with `setsid` so the reply is not blocked by a bucket write. Never put secrets or private replies in spoken output; the text is a plaintext private bucket object. The default allowlist includes the **observed** `cli`, `tui`, `ntfy` values and messaging names not verified here. Explicit `cron` and `subagent` are always excluded; Desktop is excluded until observed. Set `EARSHOT_HERMES_PLATFORMS` to narrow the allowlist. Running both path A and B can cause two spoken objects for one agent turn: enable only the path you intend. For multiplexed ntfy, first enforce an exact outbound destination allowlist and confirm the adapter's effective self-hosted server with a **nonsecret canary**; on older Hermes revisions set profile-local `NTFY_SERVER_URL` explicitly, then independently verify authenticated subscription before a real turn. Do not equate a startup `connected` line with successful asynchronous auth. Ensure the bucket is exclusive to the selected test device or get explicit consent for every other listener before writing.
